The language that compiles itself.

Statically typed, null-safe, with Kotlin's shape over a C-family syntax. Three engines that agree on every byte — and a compiler written in Keal, compiled by itself.

class Point(val x: Float, val y: Float) {
    fun length(): Float {
        sqrt(this.x * this.x + this.y * this.y)
    }
}

val points = [Point(1.0, 1.0), Point(3.0, 4.0)]
val found  = firstLong(points, 2.0)

println(when {
    found == null -> "nothing long enough"
    else -> "${found} has length ${found.length()}"
})
$ keal point.keal(3.0, 4.0) has length 5.0

CHAPTER 6 · 4 MIN

Null safety

A type does not admit null unless you write ? — and the checker will not let you forget. Four ways across:

maybe.keal ▶ Run 
var maybe: String? = null

maybe?.length              // safe call — the result is Int?
maybe ?: "default"         // a fallback
maybe!!                    // assert non-null

if (maybe != null) {
    maybe.length           // smart cast — plain String here
}

That last one is the interesting one. After a check that proves something about an immutable binding, the fact holds for the rest of the branch — and Keal carries it further than most:

if (s == null) { return }
s.length                    // narrowed for the rest of the block

s != null and s.length > 0  // narrowed in the right operand

s != null implies s.length > 0  // and across implies
✦

A var is never narrowed — anything the branch calls could reassign it — and the checker says so rather than leaving you to wonder.

The memory model

Compiling to native code makes one question unavoidable which an interpreter can dodge — what a value is in bytes, and who frees it. The short version: reference counting. Every heap object carries its count. No collector, no ownership annotations, no borrow checker.

Fields keep declaration order, padding and all — a struct whose shape the author cannot predict is one that cannot be handed to C. keal layout prints the whole table for any program, so none of it has to be taken on trust:

$ keal layout point.keal ⧉ copy 
record Point
  24 bytes, align 8, 0 of which is padding
  offset  size  field                as
       0     8  <reference count>    usize
       8     8  x: Float             f64
      16     8  y: Float             f64

Nullable niches

T? is free where a spare bit pattern exists — and says so where it is not:

TYPESIZEWHY
String?= Stringthe null pointer is the niche
Int?2 × Intevery bit pattern is a valid Int — a tag is added, and priced openly
✦

The layouts of a sample program are snapshotted in the test suite — changing a representation shows up as a diff, not as a surprise.

LEÇON 3

fun et proc

Deux mots pour déclarer, et celui que vous choisissez dit s'il y a un résultat. Une fun doit déclarer son type de retour ; une proc ne le peut pas.

Conséquence : Unit et void ne s'écrivent jamais, et consommer le non-résultat d'une proc est une erreur, pas un no-op silencieux.

§4 · EVERY SNIPPET RUNS — CHECKED BY THE TEST SUITE

when: the switch and the match

One branching-on-shape construct. No fall-through, first arm wins, and it is an expression. With a subject, arms compare against it:

describe.keal — fig. 4.1 ▶ RUN 
fun describe(n: Int): String {
    return when (n) {
        0 -> "zero"
        1, 2, 3 -> "small"       // several values, one arm
        in 4..10 -> "medium"     // a range
        else -> "large"
    }
}

is tests the type and narrows the subject inside the arm — and an arm may carry a guard, judged after its bindings are in scope.
