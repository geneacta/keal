CHAPTER 1 · 2 MIN

Hello world

One line is a program. No main, no ceremony — top-level statements run in order, on whichever engine you pick:

hello.keal
println(class="s">"hello, world")
hello, world

Three engines run the same file: the tree-walking interpreter (the specification), the bytecode VM (the default), and keal build, which compiles through C11 to a real executable. The test suite requires their outputs to match byte for byte.

✦

Everything in this tour is a real program from the repository, checked by the test suite on every run. If a snippet here fails, that is a bug.

CHAPTER 2 · 3 MIN

Values & bindings

val binds a value once; var can be reassigned. Types are inferred everywhere and written only when you want them:

bindings.keal
val name = class="s">"Ada"
val year: Int = 1815
var count = 0
count += 1
count++

println(class="s">"${name}, ${year} — count ${count}")
Ada, 1815 — count 2

Strings interpolate with ${...}. Integers are 64-bit and checked — overflow panics rather than wrapping — and there is no implicit conversion between Int and Float; only an integer literal widens.

CHAPTER 3 · 3 MIN

fun and proc

A fun returns a value and must say what it returns. A proc returns nothing, and cannot pretend otherwise — the checker holds both to their word:

functions.keal
fun area(w: Float, h: Float): Float {
    return w * h
}

proc report(label: String, value: Float) {
    println(class="s">"${label}: ${value}")
}

report(class="s">"area", area(3.0, 4.0))
area: 12.0

A return can carry its own guard: return if (a > b) a returns only when the condition holds, and falls through otherwise.

CHAPTER 4 · 3 MIN

Control flow

if is an expression; unless is its mirror. The ternary selects on a Bool — or, with three branches, on a Comp, the three-valued comparison the spaceship <=> answers:

flow.keal
val age = 20
val label = if (age >= 18) { class="s">"adult" } else { class="s">"minor" }
println(label)

println(age < 30 ? class="s">"young" : class="s">"less young")
println(3 <=> 5 ? class="s">"less" : class="s">"equal" : class="s">"greater")
adult young less

Loops are while and for (x in ...) over lists, maps, strings and ranges — for (i in 0..10) walks the half-open range.

CHAPTER 5 · 3 MIN

when

when is the branch that reads like a table — over a subject, values, ranges and types, with the checker demanding an else whenever a value is produced and the arms do not cover:

when.keal
fun describe(n: Int): String {
    return when {
        n < 0 -> class="s">"negative"
        n == 0 -> class="s">"zero"
        n in 1..10 -> class="s">"small"
        else -> class="s">"large"
    }
}
println(describe(-4))
println(describe(7))
negative small

With a subject, when (v) { is Point(x, y) -> ... } both tests the type and destructures it in one arm.

Null safety

A type does not admit null unless you write ? — and the checker will not let you forget. Four ways across:

maybe.keal
var maybe: String? = null

maybe?.length              class="c">// safe call — the result is Int?
maybe ?: class="s">"default"         class="c">// a fallback
maybe!!                    class="c">// assert non-null

if (maybe != null) {
    maybe.length           class="c">// smart cast — plain String here
}

That last one is the interesting one. After a check that proves something about an immutable binding, the fact holds for the rest of the branch — and Keal carries it further than most:

if (s == null) { return }
s.length                    class="c">// narrowed for the rest of the block

s != null and s.length > 0  class="c">// narrowed in the right operand

s != null implies s.length > 0  class="c">// and across implies
✦

A var is never narrowed — anything the branch calls could reassign it — and the checker says so rather than leaving you to wonder.

Collections & lambdas

Lists and maps are literals; lambdas are braces with an arrow. The higher-order basics are methods, and they compile to plain loops natively:

collections.keal
val xs = [3, 1, 4, 1, 5]
println(xs.sorted())
println(xs.map({ n -> n * 10 }).filter({ n -> n > 20 }))

val ages = {class="s">"ada": 36, class="s">"grace": 45}
println(ages[class="s">"ada"] ?: 0)
[1, 1, 3, 4, 5] [30, 40, 50] 36

Sequences are lazy where lists are eager: seq(xs).map(f).take(2) computes exactly two elements. Closures capture their environment — a var captured by a lambda lives in a cell both sides see.

Records & classes

A record is data: immutable fields, field-by-field equality for free. A class may carry var fields and methods. Both use one constructor syntax:

shapes.keal
record Point(val x: Float, val y: Float)

class Counter(val label: String) {
    var count = 0
    proc bump() { this.count += 1 }
}

val p = Point(3.0, 4.0)
println(p == Point(3.0, 4.0))

val c = Counter(class="s">"hits")
c.bump()
println(class="s">"${c.label}: ${c.count}")
true hits: 1

A class may declare proc deinit() — it runs when the last reference dies, at the next statement boundary, exactly once, identically on all three engines. Inheritance is a non-goal: composition and traits cover the territory without the diamond.

CHAPTER 9 · 4 MIN

Generics & traits

Generics are monomorphized — Box<Int> compiles to its own struct natively — and traits are capabilities, granted by bounds:

traits.keal
class Box<T>(val v: T)

fun larger<T: Ord>(a: T, b: T): T {
    return a <=> b ? b : a : a
}

record Version(val major: Int, val minor: Int) : Ord {
    fun compareTo(other: Version): Int {
        val m = this.major.compareTo(other.major)
        return if (m != 0) m
        return this.minor.compareTo(other.minor)
    }
}

println(larger(Version(1, 4), Version(1, 11)))
Version(major=1, minor=11)

The operators are traits too: + is Add.plus, < goes through Ord.compareTo, ** and ^/ are Pow and Root — built-ins implement them like any class would.

CHAPTER 10 · 3 MIN

The eight connectives

Boolean logic gets its whole vocabulary: and or xor xnor nand nor implies not — words, flat precedence, parentheses required where mixing could mislead:

logic.keal
val a = true
val b = false
println(a nand b)
println(a implies b)
println((a or b) and not (a xor a))
true false true

Write !(x and y) and the checker answers with a suggestion — “not (a and b) is a nand b” — a warning, never an error. Every negated connective has its own name, and the checker teaches them.

Errors & diagnostics

Every failure is a panic with a message — a failed assert, overflow, division by zero, your own throw. One catch covers them all, on all three engines, unwinding with zero leaks:

errors.keal
fun parseAge(s: String): Int {
    val n = s.toInt()
    if (n == null) { throw class="s">"not a number: ${s}" }
    return n
}

try {
    println(parseAge(class="s">"nope"))
} catch (e) {
    println(class="s">"caught: " + e)
}
caught: not a number: nope

Diagnostics explain and suggest: the note under an error says what to do, not just what went wrong. Even a Java exception arriving through the JVM gateway lands in your catch inside a native binary.

CHAPTER 12 · 4 MIN

Native code & C

keal build compiles through C11 — reference counting, deterministic layout, zero leaks under the system’s own tools. And the boundary is the C ABI, so six languages answer from one file:

interop.keal
extern fun rust_fib(n: Int): Int
extern fun go_shout(text: borrow String): own String

println(rust_fib(20))
println(go_shout(class="s">"keal"))
6765 KEAL!

keal bindgen header.h generates those declarations from any C header; import java.time.LocalDate generates typed JVM wrappers on the spot. When the backend cannot compile something yet, it refuses by name — it never mis-compiles.
