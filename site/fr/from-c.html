Je viens de C

Keal compile vers C11 : ce que vous savez de la machine reste vrai — disposition mémoire, ABI, éditeur de liens. Ce qui change : les bornes sont vérifiées, les entiers ne débordent pas en silence, la mémoire est libérée pour vous, et le système de types sait quels pointeurs peuvent être nuls.

Ce qui vous surprendra

Vous pouvez lire le C qu'il produit

keal emit-c f.keal imprime une unité de traduction autonome, runtime compris. Rien n'est caché, et keal layout imprime les décalages et le remplissage de chaque struct.

Vérifié là où C se tait

Débordement entier, division par zéro et indexation hors bornes paniquent avec un message et une ligne, sur tous les moteurs — au lieu d'être indéfinis.

La propriété à la frontière est écrite

Une String qui passe vers C dit borrow ou own ; les records passent par copie sous forme de structs miroirs sans en-tête. Le vérificateur refuse ce dont il ne peut énoncer la durée de vie.

Les cycles sont la seule fuite restante

Le comptage libère tout sauf un cycle. Écrivez weak sur l'arête arrière et il meurt comme le reste.
