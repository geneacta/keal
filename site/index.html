The language that compiles itself.

Statically typed, null-safe, with Kotlin's shape over a C-family syntax. Three engines that agree on every byte — and a compiler written in Keal, compiled by itself.

point.keal
class Point(val x: Float, val y: Float) {
    fun length(): Float {
        sqrt(this.x * this.x + this.y * this.y)
    }
}

val points = [Point(1.0, 1.0), Point(3.0, 4.0)]
val found  = firstLong(points, 2.0)

println(when {
    found == null -> "nothing long enough"
    else -> "${found} has length ${found.length()}"
})
$ keal point.keal(3.0, 4.0) has length 5.0

Interop

One file, six languages.

The native four meet Keal at the C ABI its binaries already speak — no runtime, no marshalling layer. Java and Kotlin go through one gateway module, written in Keal itself.

keal bindgen header.h turns any C header into checked extern fun declarations — a Rust staticlib, a Go c-archive, or sqlite's own.

Three engines

×84 native — with the same guarantees.

The tree-walking interpreter is the specification. The bytecode VM is the default. keal build compiles through C11 to a real executable.

The test suite runs every program through all three and requires the output to match byte for byte — integer overflow still panics, bounds are still checked.
